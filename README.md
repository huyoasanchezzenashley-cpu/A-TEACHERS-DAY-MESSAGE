## How to run

1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open `index.html` in a modern web browser.
4. Click **Open Card** or **Next** to turn the pages.
5. Click **Customize Card** to change the names, message, photo, or audio.

### Important

Modern browsers may block automatic audio playback. Use the audio player's Play button to start the included music.

## How to customize

### Change the message

Open `index.html` and edit the text inside the element with:

```html
<p id="messageText">...</p>
```

You can also use the **Customize Card** panel while the page is running.

### Change the teacher photo

Replace `teacher-photo.png` with another image using the same filename, or use the **Customize Card** file picker.

### Change the audio

Replace `teachers-day-audio.m4a` with another audio file using the same filename, or use the **Customize Card** file picker.

## Upload to GitHub

Create a new **public** repository, then upload:

- `index.html`
- `style.css`
- `script.js`
- `teacher-photo.png`
- `teachers-day-audio.m4a`
- `README.md`

Then open the repository's **Settings → Pages**, choose the `main` branch as the deployment source, and save. GitHub will provide the published website link after deployment.
